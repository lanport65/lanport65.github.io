# راه‌اندازی بسته GitHub مسعود

این بسته شامل دو خروجی مستقل است:

1. `README.md` — صفحه پروفایل GitHub
2. `index.html` + `style.css` + `script.js` — وب‌سایت Portfolio برای GitHub Pages

## قبل از انتشار

در تمام فایل‌ها این مقادیر نمونه را با اطلاعات واقعی خودت جایگزین کن:

- `YOUR_GITHUB_USERNAME` ← نام کاربری دقیق GitHub
- `YOUR_EMAIL` ← ایمیل عمومی‌ای که می‌خواهی نمایش داده شود

در README، نام پروژه‌ها و توضیحات را بعداً با مخازن واقعی و عمومی خودت هماهنگ کن. مهارت‌ها و نمونه‌پروژه‌ها در این قالب، معرفی اولیه بر اساس حوزه‌های کاری اعلام‌شده هستند؛ مواردی را که نمی‌خواهی عمومی باشند حذف کن.

## بخش اول: فعال‌کردن Profile README

1. وارد GitHub شو و یک مخزن جدید بساز.
2. نام مخزن باید دقیقاً برابر نام کاربری GitHub باشد؛ مثلاً اگر نام کاربری `masoud123` است، نام مخزن هم `masoud123` باشد.
3. مخزن را Public بساز و گزینه Add a README file را فعال کن.
4. محتوای فایل `README.md` این بسته را جایگزین README پیش‌فرض کن.
5. تغییرات را Commit کن و صفحه پروفایل را باز کن.

## بخش دوم: انتشار وب‌سایت

1. یک مخزن جدید با نام دقیق `YOUR_GITHUB_USERNAME.github.io` بساز.
2. فایل‌های `index.html`، `style.css` و `script.js` را در ریشه مخزن قرار بده.
3. در GitHub به Settings → Pages برو.
4. در بخش Build and deployment، گزینه Deploy from a branch را انتخاب کن.
5. Branch را روی `main` و Folder را روی `/ (root)` بگذار و Save کن.
6. پس از پایان انتشار، سایت در آدرس `https://YOUR_GITHUB_USERNAME.github.io` در دسترس خواهد بود.

## نکته‌های مهم

- برای سایت، نیازی به React، Node.js، دیتابیس یا هاست پولی نیست.
- فونت Google Fonts و برخی تصویر/آمارهای README از سرویس‌های بیرونی بارگذاری می‌شوند؛ برای نمایش آن‌ها اینترنت لازم است.
- اگر ایمیل یا نام کاربری را در HTML تغییر دادی، لینک‌های GitHub را هم بررسی کن.
- مخزن پروفایل و مخزن Pages می‌توانند جدا باشند؛ این بسته نیز همین ساختار را پیشنهاد می‌کند.
- پس از اولین انتشار، آدرس سایت را در README پروفایل ثبت کن.
